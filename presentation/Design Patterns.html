Singleton
Creational Design Pattern
Provide one shared instance through a controlled access point.
CASE STUDY: Shared database connection
01 / 14
Problem
Independent callers create separate database connections.
Before (direct coupling)
Solution
Hide construction; return the same instance to every caller.
After (using Singleton)
Client Code (Before)
Pseudocode
a = new Database() b = new Database() a.query(sql) // a and b are different objects
Client Code (After)
Pseudocode
a = Database.getInstance() b = Database.getInstance() a.query(sql) assert a is b
Key Implementation / Notable Module
Pseudocode
// Database: lazy, thread-safe accessor static synchronized getInstance(): if instance == null: instance = new Database() return instance
Source: https://refactoring.guru/design-patterns/singleton

Builder

Proxy
Structural Design Pattern
Control access to a service through the same interface.

08 / 14

Solution

After (using Proxy)
Client Code (Before)
Pseudocode
service = new ThirdPartyVideoService() a = service.downloadVideo(id) b = service.downloadVideo(id) // two remote requests
Client Code (After)
Pseudocode
service = new CachedVideoProxy(realService) a = service.downloadVideo(id) b = service.downloadVideo(id) // second request uses the cache

State

Observer

Command
Behavioral Design Pattern
Represent a request as an object that can be invoked and undone.
CASE STUDY: Undoable text-editor actions
14 / 14
Problem
Buttons and shortcuts duplicate editing actions without shared undo.
Before (direct coupling)
Solution
Bind both triggers to a command; store successful edits in history.
After (using Command)
Client Code (Before)
Pseudocode
pasteButton.onClick(() => editor.insert(text)) shortcut.onPress(() => editor.insert(text)) // duplicated action; no undo record
Client Code (After)
Pseudocode
paste = new PasteCommand(editor, text) pasteButton.bind(() => app.execute(paste)) shortcut.bind(() => app.execute(paste)) app.undo()
Key Implementation / Notable Module
Pseudocode
// PasteCommand.execute() backup = editor.text; editor.insert(text) return true // app records command in history // undo(): editor.text = backup
